# laboratorio-de-soluciones

Landing estatica preparada para publicarse desde GitHub Pages.

## Publicacion en GitHub Pages

1. Entra en la configuracion del repositorio en GitHub.
2. Abre la seccion Pages.
3. En Source, selecciona Deploy from a branch.
4. Elige la rama principal y la carpeta root.
5. Guarda los cambios. GitHub publicara index.html desde la raiz del repositorio.

## Archivos principales

- index.html: estructura de la landing.
- styles.css: estilos y responsive.
- script.js: animaciones suaves y ano actual del footer.
